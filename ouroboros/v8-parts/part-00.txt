<!--
OUROBOROS POSE EDITOR — WORKING SPEC (v8)

Single-file, offline, touch-first HTML app for dev HTML Playground (dHP) on iPhone.
This file is an incremental extension of the supplied working baseline: preserve the canvas
renderer, continuous Catmull-Rom snake, point-zero HEAD / last-point TAIL semantics,
TAIL→HEAD arrows, Edit/Move/Pan separation, viewport-only pan/zoom, endpoint controls,
diagnostics, snapshots, JSON import/export, collapsible mobile UI, and iOS compatibility.

Scene depth is 0..14 with 6.5 as the normal reference and larger values closer to viewer.
Perspective Strength affects apparent illustration scale/thickness independently of viewport
zoom. Earth has x/y/depth/scale/lock state; Moon is Earth-relative and follows Earth.
Snake control points carry x/y/depth/manual-width/Earth-topology/contact metadata.
Explicit Earth and self-crossing topology overrides always beat automatic classification.

Input model:
- Tap/left-click a control point to select it; drag it in Edit mode to pose it.
- Move mode moves only the snake. Pan mode moves only the viewport.
- When Earth is unlocked, dragging Earth in Edit mode moves Earth (and therefore Moon).
- Long-press a snake segment to insert a control point at that curve location.
- Long-press a control point opens point actions; right-click opens the same contextual menu.
- Double-click a snake segment inserts a point. Existing Add/Delete buttons remain available.
- Two-finger pinch and two-finger translation zoom/pan the viewport simultaneously.
- Mouse wheel/trackpad zooms around the pointer; Shift+wheel pans; middle-drag or Space+drag pans.
- Keyboard: E/M/P modes, Cmd/Ctrl+Z undo, Cmd/Ctrl+Shift+Z redo, Delete/Backspace deletes an
  eligible point, +/- zooms, Escape closes transient UI. Shortcuts are suppressed in form fields.

All numeric slider controls expose minus/plus buttons and an editable numeric value. Typed
values clamp to the control range. Holding minus/plus repeats. One slider or held-button gesture
creates one undo step. Viewport pan/zoom is excluded from undo history.

Undo/redo stores compact meaningful scene snapshots (limit 50). Autosave uses localStorage and
restores on reload. JSON schema is version 8. Version-4 signed-depth JSON is migrated with
z -> clamp(z + 6.5, 0, 14); version-7 state is accepted with obsolete Length Lock and pixel-filter
fields ignored. Named checkpoints store pose snapshots but checkpoint creation/deletion does not
pollute pose undo history.

Topology: Earth occlusion is automatic with per-point AUTO/FRONT/BEHIND overrides. Self-crossing
analysis uses polyline segment intersections clustered by stable control-span pairs; manual crossing
front choices survive ordinary point motion and are remapped where practical across point insertion/
deletion. Diagnostic view can show transitions, crossing markers, contacts, gaze, depth and guides.

Additional editor features: Earth/Moon controls; snake outline; profile head rotation, neck width,
eye openness/position/gaze, mouth openness and diagnostic gaze arrow; tail direction/curvature;
manual body-width multipliers; contact markers/shadows; ouroboros reference circle, mouth-to-tail
guide and closure preview; one simple directional illustration light; clean/diagnostic modes;
current spline arc-length readout; clean/diagnostic snapshots; gesture-help sheet.

Removed by design: Length Lock/constraint solver and pixel-art post-processing. They proved harmful
or unhelpful to posing and are intentionally not part of schema v8.

Non-goals: no animation, WebGL, arbitrary 3D camera rotation, physics engine, skeletal rig,
real orbital simulation, axial Earth rotation, PBR, multiple lights, or ray tracing.
-->
